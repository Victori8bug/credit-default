# Model validation report: credit card default model

Generated by `scripts/build_validation_report.py`. Every number below is recomputed from the code each time the script runs. This is a student project, not a regulatory document.

## 1. Purpose and scope

The model estimates the probability that a credit card account defaults next month. It supports an approve/decline policy (approve when PD is below 14%), expected-loss measurement and stress testing. It was developed on 21,000 accounts and tested on 9,000 accounts held out from development.

## 3. Conceptual soundness

**Design.** Logistic regression on nine engineered inputs. Demographic fields are excluded from the inputs.

| Input | Coefficient |
|---|---|
| months_late_now | +0.515 |
| count_months_late_6m | +0.308 |
| worst_months_late_6m | +0.201 |
| log_credit_limit | -0.199 |
| paid_in_full_now | +0.196 |
| utilization | +0.103 |
| no_balance_now | +0.094 |
| log_last_payment | -0.093 |
| payment_ratio | -0.007 |

**Finding 1 (open).** `paid_in_full_now` and `no_balance_now` carry positive coefficients: accounts that paid in full or had no balance are scored riskier than accounts paying the minimum on a revolving balance. The sign reflects this dataset but is counter-intuitive, and it surfaces as a reason code. It should be investigated (for example by grouping the repayment codes differently) before the reasons are relied on.

## 5. Stress testing

| Scenario | Average PD | Expected loss | Change vs baseline | Approval rate at cutoff |
|---|---|---|---|---|
| Baseline | 22.0% | 106,186,198 | +0.0% | 52.0% |
| Adverse | 25.9% | 130,061,439 | +22.5% | 49.9% |
| Severe | 34.3% | 191,750,935 | +80.6% | 15.1% |

- **Adverse:** Payments fall 25%, balances rise 10%, accounts already late slip one more month.
- **Severe:** Payments fall 50%, balances rise 25%, every account carrying a balance slips one month.

Scenarios are hypothetical shocks to model inputs, not forecasts linked to economic variables.

## 8. Limitations

- Existing cardholders in one market (Taiwan) over six months in 2005; not new applicants and not a normal credit cycle.
- LGD, CCF, margin and risk-grade bands are assumptions, not estimates.
- One 70/30 random split; no out-of-time test because the data has a single observation date.
- The developer and the validator are the same person here. Real validation requires independence.
